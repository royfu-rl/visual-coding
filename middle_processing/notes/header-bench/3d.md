1. 三个 benchmark 各占一条技术栈：CAD、Blender、three.js
2. BenchCAD
   - 选 with tools，因为只有这个设置有 GPT-6 Astra（OpenAI 没发 without tools 分数）
   - 分数挤在 81.6–96.2，接近天花板。想拉开差距就改用 without tools：41.2–73.0，4 个模型，没有 Astra
   - Kimi 这张表是拼起来的，图注要写清楚：
     - Claude 的分数取自 Anthropic system card（Anthropic 自己的容器 + 图片裁剪工具，5 次平均）
     - Astra 取自 OpenAI 公布值（harness 和子集未说明）
     - Kimi 和 DeepSeek 由 Kimi 自跑（Claude Code harness）
     - 各家都是"随机 1,000 例子集"，但不是同一个子集
   - BenchCAD 官方榜把以上所有分数都标成"厂商自报、未重新评分"
3. BlenderWorld
   - 只有论文这一张表（13 个模型）。项目页数据和论文完全一致，repo 里没有排行榜，最后一次提交是 2026-10-20
   - 缺口很大：没有 Opus 5.5、Fable 5.1、Gemini 4、Kimi K3.1 Pro，只测了旧版 Opus-5 和 Kimi-K3
4. Design Arena 3D
   - 分数来自人类两两盲投，不是确定性 verifier；Elo 不是 0–100 的分数
   - 画柱状图必须截断 y 轴并标注，或者改画胜率
   - 想要确定性指标，就换成 3JSBench（pass rate 0–100），但它只覆盖 3 个 zoo 模型（见第 3 节）

## 4 与旧笔记 `parts/3d/bench.md` 的冲突

1. 旧笔记写 "OpenAI 报 GPT-6 Astra 95.9%（geometric overlap）"
   - Anthropic、Kimi、BenchCAD 官方都把这个指标称为 voxel IoU
   - OpenAI 原页返回 403，没能核对 OpenAI 自己的措辞
2. 旧笔记写 "Claude Opus 5 0.366 / 0.821"
   - 这是 128px 低分辨率实现下的旧值，Anthropic 已经作废
   - 新值是 0.497 / 0.899，见 Opus 5.5 system card §8.13.2
3. OpenAI 在 Astra 发布表里引用的 Fable 5.1 84.3、Opus 5 82.1，也是同一批低分辨率旧值
4. 旧笔记写 "3JSBench Opus 5.5 49.0%"
   - 这个数出自 battle cohort（2026-09-25，10 个模型）
   - 3JSBench 当前的 release cohort（2026-09-23）只有 5 个模型，不含 Opus 5.5
