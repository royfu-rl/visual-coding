# 两本书：Williams 定原则，Refactoring UI 管网页

**结论先行。** 3.3 rubric 的出处定为两本书，各自是一个圈子里影响最大的视觉设计书：

- **Robin Williams《The Non-Designer's Design Book》**（1994 初版，2015 第 4 版）：国内和教学圈的事实标准
  - 中译本《写给大家看的设计书》是豆瓣上评分人数最多的网页 / UI 类设计书：第 3 版 13,054 人、第 4 版 3,204 人，评分均为 8.6
  - 国内最主流的前端设计体系 Ant Design，设计原则里的「亲密性、对齐、对比、重复」就是这本书的四原则；Ant Design 3.x 的参考书页把它列为「inspired us」的书
  - NN/g 视觉设计书单收录：「A thin book that provides a quick introduction to many of the same visual design principles」
- **Adam Wathan & Steve Schoger《Refactoring UI》**（2018）：英文前端开发者圈讨论最多的视觉设计书
  - 专门写给开发者；作者之一是 Tailwind CSS 的作者
  - Hacker News 相关条目：「Building Your Color Palette」1,019 分、705 分，「7 Practical Tips for Cheating at Design」480 分
  - 对 A1–A10 覆盖最全：10 条都能对到官方目录里带页码的小节

两本互补：Williams 管结构类原则（A1–A3、A8），Refactoring UI 管网页落地的其余规则。两本的写法都是「规则 + 改前改后对比图」，和 3.3「rubric + 一对示例」同构。

## 2 为什么是这两本

1. 影响力有据可查，而且正好覆盖本项目的两类读者：国内团队（Williams 的中译本与 Ant Design）和写代码的人（Refactoring UI）
2. 合起来覆盖 A1–A10：Refactoring UI 10 条都有带页码的小节；它偏弱的对齐、一致性由 Williams 的 Alignment、Repetition 补上
3. 写法同构：都把规则写成可观察的句子，并用改前改后的对比图讲道理，可以直接改写成问 VLM 的二选一问题
4. 出处可核对：Refactoring UI 官方目录带页码〔一手〕；Williams 原句只有二手转引，所以 rubric 表里只写章名

## 3 没选的，以及为什么

- **Mullet & Sano《Designing Visual Interfaces》**：机构背书最强（NN/g 称「the number one book about visual design」），但出版于 1995 年、讲桌面软件，原文只能核对前三章大纲，国内无译本
- **Universal Principles of Design**：覆盖互补性最好，但它是覆盖产品、建筑等所有设计的百科，不专讲视觉；国内评分人数只有几百
- **The Design of Everyday Things、Don't Make Me Think**：影响最大，但讲可用性，不讲网页视觉规则
- **Bringhurst、Lupton、Müller-Brockmann**：艺术设计院校经典，但只管排版或栅格，各自只覆盖 A2、A4、A5

## 4 局限与缺口

- 本轮四路调研里「影响力数字」一路因账号登录过期中断；销量只有二手数据，Google Scholar 被引次数未取到
- Refactoring UI 的影响力几乎全在英文开发者社区，没有课程采用证据，也没有中译本
- Williams 的影响力集中在入门教学与国内；原句（如「Nothing should be placed on the page arbitrarily」）只有二手转引
- A4 的数字（45–75 字符）与 A7 的阈值（4.5:1）两本书里都没有可核对的原文，仍分别取自 Bringhurst / Butterick 与 WCAG
- Open Syllabus 的课程出现次数没拿到（页面 404），这是最值得补的一手数据源
