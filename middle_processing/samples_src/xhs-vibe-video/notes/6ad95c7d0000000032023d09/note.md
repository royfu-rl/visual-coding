Claude 推出新应用 Claude Duet，开放研究预览。在 Duet 里，Claude 是一个主动的智能体：有事先来找你，交给它的任务自己做完，你走开了它接着干，要替你行动之前先问你。同类产品还有 OpenAI 的 Dot 和 xAI 的 Grok Bot。

官方短片里的一天：咖啡店老板早上收到简报；Duet 从收银、网店、客户管理、薪资和银行拉数据做成每日看板；主动提醒新店卫生许可还没申请，并把申请表起草好；告诉你哪份续约可以等；起草录用邮件，最后点发送的还是老板自己。
	
产品页演示：连锁咖啡公司 Marlo 的 41 项开业清单、640 美元许可费等你点批准、A 轮融资的路演稿和资料室准备，以及经营看板发现订阅流失率上升并建议包邮测试。
	
判断力从哪来：Duet 围绕 Claude Opus 5.5 设计，判断哪些事需要你、哪些可以等、什么时候先问你；沿用 Claude 账号的记忆、技能和已连接的应用；在云端有自己的虚拟电脑和浏览器，手机电脑关着也能干活。
	
能接的应用：Claude 应用市场里六千多个连接器和插件；替你买东西时用 Stripe 的 Link 生成虚拟卡付款。
	
安全：不直接看到密码；新分类器防止敏感信息外泄；发消息、付款、签文件、删除之前都要你批准，交易证券和账户间转钱批准了也不做。
	
目前面向美国 Pro 和 Max 用户，需要排队申请。
