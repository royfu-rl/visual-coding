# Coding Worlds for Evolving Agents

持续进化的智能体需要一个能够持续交互的环境：采取行动、观察结果，再决定下一步。转过转角，视野随之改变；推开物体，后续可能发生的交互也随之变化。这一连串行动与反馈，构成了智能体的经验。
	
基于代码的环境让我们能够完全掌控物理交互：物体、规则以及状态的每一步变化，都可以在代码中明确定义并被精确追踪。但其画面质量受制于三维资产与渲染管线：程序搭建的场景往往只有简化的几何体、重复的贴图和生硬的光照，让成百上千个环境都足够逼真的成本极高。
	
以视频生成为核心的世界模型提供了另一条路径：通过相机视角与动作指令驱动画面生成，输出极为逼真的视觉画面。然而在这类系统中，物理世界的信息大多隐式包含在生成历史与模型记忆中。视频能维持视觉上的连续性，却无法提供一个可供直接查询与干预的显式世界状态。
	
因此，我们将代码环境与实时神经渲染器结合：代码决定世界如何变化，神经渲染器呈现这些变化看起来是什么样。与一次性生成整段视频的方法不同，我们的渲染器按短块接收环境导出的流式条件，逐步合成视觉画面。智能体可以采取一次短暂行动，观察结果，并据此决定下一步策略。@MirroS
