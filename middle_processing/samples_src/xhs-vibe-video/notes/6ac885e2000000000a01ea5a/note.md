# Claude 把数据仪表盘做成动画

📊 Claude 新上了两种 Artifact 类型：Claude Dashboards 和 Claude Motion，目前都是 beta。演示的人是 Anthropic 设计师 Nate，之前用 Claude 做 PPT、做 App 原型的也是他。这次他假设自己在共享单车公司带运营团队，遇到一个具体问题：山坡上的车桩，每个工作日 8:15 之前就空了。
	
🗂 第一步，出仪表盘
他让 Claude 从公司数据仓库里拉出一年的骑行数据，排成一张仪表盘。每日骑行量、分时段曲线、各站点早高峰的出车情况都在一页上。看着这张仪表盘，事情的来龙去脉慢慢清楚了。
	
🎬 第二步，把仪表盘改成动画
这个结论要在下次全员会上讲给整个团队，让大家都支持。他让 Claude 用 Claude Motion 把这张仪表盘改成一段数据动画：一张街区地图，时间从清晨往后走，Fernhill 站点的车越来越少。
	
💬 第三步，边看边改
Nate 说 Claude 的第一版通常就不错。想调的地方，直接在视频画面上写评论，Claude 照着改。动画可以发给同事，同事也能评论，几个人一起把这个故事磨出来。团队想再加工，可以导出到他们的设计工具里。
	
🧭 查数的人多半也要负责把结论讲出去，而一页图表不一定能让不看数据的同事跟上。Claude 这次把出仪表盘和做数据动画放进了同一条流程，做汇报的人可以少换几次工具。
