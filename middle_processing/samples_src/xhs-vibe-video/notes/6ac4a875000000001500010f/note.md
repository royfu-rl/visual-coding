# X上爆火！用来做短视频绝了

- 命中关键词：Claude 科普动画、Motion Canvas、视频 skill

这次把做艺术动画的方法，整理成了一个开源skill：huashu-art-motion。
前4张是实况图，里面的人物和画面都在动。莫奈的日本桥可以打水漂，埃及壁画里的圣甲虫会推着太阳走，到了8-bit场景，还能顶出一枚金币。
起点是一次复刻。我把参考动画丢给Claude Code，让它拆解画风和运动，后来又用我的卡通形象，做了一支穿越不同名画的短片。场景、运镜和配乐靠代码，人物则用生图模型生成动作帧，再由代码合成。
我更想留下的，是下次换题材还能用的方法。所以把风格配方、拆参考视频的做法、角色怎么生帧、配乐怎么卡节奏，都收进了这个skill。
里面有35种艺术画风和9种解说语法，其中8种可以按口播参数渲染片段。除了做艺术短片，也可以给课程、科普或软件教程配一段白板、拼贴、图表动画。最后一张就是白板和Vox拼贴的实际效果。
装好后，可以直接对agent说： 「用梵高《星月夜》的风格，给我做一段15秒的动画，画面里的东西要一直在动。」 也可以把自己的口播或参考视频交给它。
GitHub： alchaincyf/huashu-art-motion
安装命令： npx skills add alchaincyf/huashu-art-motion
需要的渲染环境，可以直接让agent帮你装。画面里要出现你自己，就给它角色参考图；没有生图能力，也能先从纯代码画的场景和几何角色开始。
