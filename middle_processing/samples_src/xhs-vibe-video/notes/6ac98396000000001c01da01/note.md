最近发现，已经有不少开发者开始用 Opus 5.5 做视频、动画和特效了。
不需要从零摸索，我整理了 5 个值得关注的 GitHub 开源项目，涵盖视频案例、提示词、纯代码动画和 Agent Skills。
01｜awesome-opus5-5-videos
提示词和视频案例整理得比较清晰，适合新手直接参考、复用。
02｜lemo-opuscar
内置 43 种纯代码影片风格，适合研究视频创意、镜头设计和不同的视觉效果。
03｜awesome-claude-video
偏技术实现，重点关注动画生成、渲染管线和制作流程。
04｜awesome-opus-5.5-video
视频案例合集，涵盖 Opus 5.5 和 Sonnet 5.5，适合寻找灵感和参考项目。
05｜awesome-opus-video-skills
收集可安装的视频类 Agent Skills，适合想直接上手视频制作工具的开发者。
使用方法也很简单：
① 打开 GitHub，搜索对应项目名称。
② 复制项目仓库链接。
③ 把链接丢给 Codex 或 Cursor。
④ 让 AI 阅读 README，帮你分析项目、整理使用方法，或者按需安装和改造成自己的 Skill。
建议先收藏这张图，需要做 AI 视频的时候直接拿出来参考。
