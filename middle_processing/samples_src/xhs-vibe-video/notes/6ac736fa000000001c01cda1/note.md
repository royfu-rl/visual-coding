# GPT-6 Astra 居然在浏览器里跑出了 3D 溪流

今天刷推看到 @chetanankola 分享的最新实验，连 OpenAI 官方都跑来评论直呼“soothing 🧘”。
他用 GPT-6 Astra 直接构建了一套纯浏览器端运行的 3D 交互场景 —— Cozy Creek（惬意溪流）。
全流程由 Blender 制作资产配合 Three.js 渲染，甚至无需本地复杂环境，直接在网页里平滑运行！尤其是夜晚模式下的月光波光粼粼反射，水流物理感和氛围感直接拉满。
重点是作者还公开了 Codex 的“军规级”构建消耗清单（Hiroshi’s island 系列）：
总 Token 消耗：约 317.37M（超 3.1 亿 Token）
上下文缓存命中率：高达 97.7%（缓存省了大成本）
实际输出：约 1.28M Token（包含推理思考过程）
水体着色器：复用了 Drop3 平台的无限水流算法
现在的 AI 已经不仅是写简单的 CSS 动效，配合 Three.js、WebGL 和着色器，复杂的 3D 交互环境已经可以直接用自然语言协同生成迭代了。
大家觉得这种全 AI 辅助编写的 3D 场景，未来多久能完全应用到轻量级 Web 游戏和沉浸式官网设计里？
