# 新一代航空母舰入列JavaScript + Canvas

- 命中关键词：Motion Canvas

最近用 AI 做了 3 个 pixel art 像素微缩场景：
	
🏏 会自动投球、挥棒、追球的板球场
⚡ 皮卡丘对战大岩蛇的小擂台
🛫 带甲板小人、海浪和战机起飞的辽宁舰
	
很喜欢这种感觉：像把一个小世界放在桌面上，凑近看，每个角落都在动。
	
更有意思的是文件体积👇
板球场的完整单文件网页约 **25.7 KB**，辽宁舰约 **30.4 KB**。
这里统计的是网页源码，导出的 GIF、视频体积另算。
	
场景由 JavaScript + Canvas 绘制。代码记录物体怎么画、怎么运动，浏览器再实时生成画面，所以不用保存每一帧。
	
分享一下我的制作思路：
	
**① 先把“微缩感”说清楚**
只写“像素风”太宽泛。我会补上：等距俯视、微缩模型、浅色背景、大面积留白、统一像素颗粒、柔和阴影。
	
**② 先搭场景，再加细节**
先确定球场、擂台、甲板的形状和比例，再补人物、草地、碎石、海浪。第一轮先把构图做好。
	
**③ 把动画拆成具体动作**
比如“飞机起飞”，继续拆成：滑跑、加速、抬头、离舰、飞出画面。
板球则是：助跑、出手、挥棒、追球、捡球、回传。
	
动作越具体，越容易发现哪里需要改。
	
**④ 打开预览，一次改一个问题**
这几个项目里，花时间最多的就是动作衔接：球有没有碰到球棒、人物会不会突然归位、飞机离舰有没有跳一下。
这些细节调顺，小世界才有生活感。
	
想试的话，可以从这段提示词开始：
	
「用原生 JavaScript + Canvas 制作一个【主题】像素微缩场景。采用等距俯视构图、浅色背景和大面积留白，统一像素颗粒，用明暗和投影表现体积。先完成静态场景，再加入连贯的循环动画。尽量使用程序绘制素材，做成可离线打开的单个 HTML，目标控制在 100 KB 以内。」
	
这套方法不限定某个模型，**有代码生成能力的模型都可以尝试**。重点是把画面要求讲具体，再对着预览慢慢调整。
	
看着几行动作描述，最后变成一群在小球场里认真跑动的人，还挺治愈的。
