# 用代码当导演，精准控制AI视频

- 命中关键词：纯代码视频

🎬 介绍我们的 Code Video Model！把编程智能体变成可控视频生成的引擎。
	
视频模型越来越逼真，但物理规律和精确控制仍是难点：抛出的球可能悬浮，摆动周期可能漂移，碰撞看似合理却不符合物理。角色姿态、物体位置、运动轨迹、镜头时序，也很难只靠提示词逐一控制。
	
💻 我们借鉴电影预演：让编程智能体把提示词写成可执行的代码场景。布局、运动、镜头轨迹和事件时间，都放进可编辑的代码里。先渲染一段简化的预演视频，确定时空结构；再用参考图设定外观，由视频模型补上几何细节、材质与光照。
	
整个流程是：写代码 → 预演 → 检查 → 修改 → 生成视频。比如调整机器人的路径点，就能改变行进路线，同时保留场景其他部分。程序准备好后，预演渲染不到一分钟，方便快速验证和迭代镜头设计。
	
🔍 难点在于：预演视频通常很粗糙，直接作为条件输入，模型容易连低多边形外观也一起照搬。
	
🔍 观察：我们在冻结 MiniMax-H3 的实验中观察到：
• Qwen-VL 通路对外观影响更强，VAE 通路更多影响运动和结构，两者互补。
• 预演条件在去噪前约 25% 的阶段尤其关键；移除后，早期结构引导仍会留下影响。
• 移除太早，结构容易偏离；保留太久，粗糙外观又会残留。
	
⚙️ 方法：因此我们提出免训练的分阶段条件控制：早期保留完整预演和两条原生条件通路，建立结构与运动；之后移除预演，让文本、参考图和模型先验继续细化外观。视频模型保持冻结，无需额外训练控制模块。
	
🚀 从动漫、子弹时间、游戏和场景编辑，到机器人轨迹、建筑与产品运镜、物理运动及 3D/4D 重建，都可以从一段可执行代码开始。
