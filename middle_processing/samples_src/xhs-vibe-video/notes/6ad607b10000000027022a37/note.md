腾讯视频·大模型算法团队开放研究实习岗位！研究方向覆盖两条相互协同的主线：Code World Model 与 Omni Video Dataset & Model。
	
📍 地点：深圳 / 北京
⏳ 周期：实习 6 个月及以上优先
🎯 目标：推进完整研究，面向高质量顶会投稿
	
🔥 两条研究主线
1️⃣ Code World Model
探索代码、智能体与视频生成模型融合的新范式，方向包括 Agentic Video Generation、Code-driven Generation、3D / Motion、World Model 等。
	
2️⃣ Omni Video Dataset & Model
围绕全能视频数据与模型，重点研究：
全能参考生成：统一处理角色、物体、场景、动作、运镜、风格、结构及叙事等异构参考；
视频编辑：研究主体替换、属性编辑、风格迁移、局部重绘、运动与镜头调整、长视频一致性等。
	
团队近期已开源首个全能参考视频数据集 Omni-R2V Dataset，并发布配套评测基准 OmniVBench，论文月下载量超过 1.5 万。📈
