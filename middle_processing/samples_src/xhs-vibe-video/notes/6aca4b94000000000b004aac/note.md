# 10套开源视频与动画Skills

- 作者：晓点技术　类型：normal　赞 72 / 藏 165 / 评 1
- 链接：https://www.xiaohongshu.com/explore/6aca4b94000000000b004aac?xsec_token=ABIjxpLJeqS3QjjOpGf_WvMisItdKj096qIQlNsGSSYVA=&xsec_source=pc_search
- 命中关键词：HyperFrames、Motion Canvas、视频 skill

按 GitHub 仓库总 Star 排序并逐项核验，整理了 10 套开源视频与动画 Skills。每套都有明确开源许可，并标出开源制作路径，覆盖网页动效、白板手绘、数学动画和本地剪辑。
	
01｜OpenMontage｜★ 66,014
想把选题、脚本和后期串起来，可以看 OpenMontage。用自备素材加 FFmpeg，就能走开源制作路径。
	
02｜HyperFrames｜★ 60,139
会写网页，就能沿用 HTML 和动画代码做视频。产品介绍、动态图形和字幕包装都有对应流程。
	
03｜SRT 白板动画｜★ 4,224
手里已有课程字幕或故事口播稿，可以把内容做成逐笔绘制的白板动画。线稿和区域时序需要先确认。
	
04｜OpenStoryline｜★ 3,472
想通过聊天调整素材、脚本和剪辑，可以看看 OpenStoryline。它需要先部署服务，再由配套 Skills 调用。
	
05｜Drama Skills｜★ 2,698
做短剧时，可以用它管理剧本和分镜，再用 FFmpeg 剪自备镜头。开源路线覆盖编剧与后期。
	
06｜Pixel2Motion｜★ 2,407
有一张 Logo 图，想做可改代码的片头动效，可以看 Pixel2Motion。先把矢量形状做准，再安排动画。
	
07｜Lemo-Opuscar｜★ 1,753
想做有画风的短片，又希望画面由代码生成，可以看 Lemo-Opuscar。Canvas、WebGL 和本地合成是它的主要路线。
	
08｜Manim Skill｜★ 1,155
公式推导、函数图像和几何演示，Manim Skill 更对路。Community 与 GL 是两套入口，先选定版本。
	
09｜Video Spec Builder｜★ 1,017
脑子里有视频想法，却说不清每个镜头怎么拍，可以先用 Video Spec Builder。产物是分镜文档，再交给渲染工具。
	
10｜Clipify｜★ 587
已有访谈或播客长视频，可以用 Clipify 挑片段、做竖屏和逐词字幕。转写与剪辑都在本地完成。
	
先看要做哪类视频，再看开源制作路径。可选云服务和其他许可组件需单独检查；安装前审查源码、权限、依赖和文件修改范围。Star 只代表关注度。
