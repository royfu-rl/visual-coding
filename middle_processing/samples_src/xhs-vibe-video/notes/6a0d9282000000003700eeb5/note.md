# HyperFrames vs Remotion vs FFmpeg

- 命中关键词：Remotion

说到 AI 做视频，一定绕不开这 3 个东西：HyperFrames、Remotion、FFmpeg
很多人第一次看： 名字都认识， 但完全不知道它们到底是什么关系。
	
简单来说
[气球R] HyperFrames 负责： 「AI 怎么理解视频」
[气球R] Remotion 负责： 「怎么把视频画出来」
[气球R] FFmpeg 负责： 「怎么把视频真正处理和输出」
	
三者关系其实像：
🧠 HyperFrames = 导演/编剧 ，关注：镜头、节奏、叙事
🎬 Remotion = 摄影棚/拍摄系统 ，关注：组件化生成视频画面
⚙️ FFmpeg = 后期剪辑压缩工厂，关注：编码、转码、压缩、推流
	
它们不是竞争关系， 而是 AI 视频生成链路里的不同层。
	
AI 视频平台，本质都是：LLM + HyperFrames + Remotion + FFmpeg
	
但其实Agent + FFmpeg，就已经可以生成视频了。
而 HyperFrames + Remotion的出现， 解决的不是“能不能生成”，而是：
❶ 流程是否更简单
❷ 视频质量是否更高
❸ 是否更容易规模化
