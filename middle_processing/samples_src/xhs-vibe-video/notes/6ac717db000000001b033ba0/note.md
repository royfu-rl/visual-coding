# Claude+Blender做个人网站，效果太炸裂了

刷到用 Blender + AI 做的个人网站，当场被帅到。于是照着这个思路，用 Claude + Blender 给自己也做了一个，打磨了很久，代码已经全部开源。
	
如果自己设计，可以换其他的古风，欧式等等等等，随便扩展风格
	
🖥 怎么做的
1️⃣ 把参考截图和我自己书桌的照片一起发给 Claude
2️⃣ 我的桌子实在不好看，就让它改：「高级一点，落地窗、高楼，或者 loft 那种」
3️⃣ 后来又补了一张工位的图，想加什么就直接跟他说：摄影、新闻、唱片机、友链都搬上了桌。还有我桌上那盘薯条也让它都建进去了🍟
4️⃣ 建模不用手捏：Claude 写 Python 脚本，Blender 在后台自己把场景搭出来
	
十种画风怎么来的 不是渲十遍成品。同一个机位只出一组「通道」：底色、物体 ID、法线、深度、5 组灯光，再用 Python 做后期： · 墨线 = ID / 法线 / 深度发生突变的地方 · 阴影 = 光照分几档，暗部铺网点和排线 · 最后换配色和纸纹 一套通道出漫画、黑白默片、波普、水彩、朋克拼贴、霓虹、像素、手稿……
	
网页上的特效 · 换宇宙：WebGL 着色器把画面切成方块一块块翻过去，带横向错位和 RGB 分离，还会蹦一个漫画拟声词 · 悬停描边：ID 图顺手当热点图，鼠标指到哪个物件就描哪个 · 点物件镜头会推过去，推近自动换 4K 贴图 · 黑白宇宙会下雨，霓虹宇宙有扫描线 · 唱片是真能放歌的黑胶唱片机，杯子点开是友链蛛网，显示器里能跟我的 AI 分身聊天 整个站纯静态，没有框架，没有构建步骤。
	
📦 开源 GitHub 搜 EdwinjJ1/personal-website，MIT 协议。README 里写了怎么换成你自己的：改文案不用重新渲染，换桌上的东西只改一个 Python 文件。
