# Claude Opus 5.5 怎么做视频的

- 作者：卡帕东　类型：normal　赞 35 / 藏 33 / 评 2

- 命中关键词：Claude Code 做视频、Claude 做视频、Remotion

别被「Opus 5.5 生成视频」这个词骗了。
	
Opus 5.5 没在生成画面，它在写程序。10 秒视频就是 300 张静态图，每一帧该长什么样都由代码算出来，再让无头浏览器一帧帧截图，FFmpeg 拼成 MP4。
	
所以强项很直白：文字不会错、能精确对齐旁白、改一行代码就重出、同一份代码每次结果一样。弱项也很直白：画人脸和动物一塌糊涂，一支 3 分钟短片吃掉每周额度约 7%。
	
我更在意的是另一件事——这套流程已经有现成工具了，HyperFrames、Remotion 都给了智能体技能包。能不能出片，越来越取决于你会不会把需求讲清楚、有没有审美把关，而不是会不会写动画代码。
