# AI视频可控小技巧：通过Blender做分镜图

- 作者：陆三金　类型：video　赞 121 / 藏 190 / 评 3　时长 80s
- 链接：https://www.xiaohongshu.com/explore/6ad9b245000000003103756d?xsec_token=ABRXR_NYOa-6BpvTR6R8HJptSOoBe8WJmwJ8goEiZ3gOY=&xsec_source=pc_search
- 命中关键词：Claude Blender 动画

① 让 Agent 通过 MCP 操控 Blender；
② 打字让它搭简易灰模、定好比例，逐镜头做出整部片的预演；
③ 关键一步：不把预演视频直接喂给模型，而是让 Agent 截关键帧，做成带编号的分镜图，连同设定图一起交给视频模型，并在提示词末尾加上三句 STORYBOARD 指令。
	
镜头一下从僵硬变灵动，一致性也很强。
