# Code2Video: 10 个高质量项目推荐

- 作者：Mazy　类型：normal　赞 180 / 藏 300 / 评 
- 链接：https://www.xiaohongshu.com/explore/6acb43430000000018004576?xsec_token=ABy8oDcatVbkkl_B3KWyHR9Ik3GqBfM7OUAMXPI_4fSSc=&xsec_source=pc_search
- 命中关键词：AI 写代码做动画、HyperFrames、Motion Canvas、Remotion、代码生成视频

最近 Code2Video 好火啊：让模型自己写动画代码，再用浏览器或者渲染引擎出片。
说白了就是——视频不用拍，全是代码写出来的。
为大家整理了 10 个值得一看的项目 👇
	
🎬 完整 Pipeline
- Lemo-Opuscar: 43 种影片风格，带分镜和导演指南
- PDoomVideo: 整支 MV 的分镜＋渲染源码
	
📄 论文
- TheoremExplainAgent: 自动把定理讲成动画＋旁白（ACL 2025）
- Code2Video: 规划→写码→自检的闭环，自动产出讲解视频 (ICML 2026)
	
🛠️ 动画框架
- HyperFrames: 用 HTML/CSS/JS 写视频，逐帧渲染
- Remotion: 视频写成 React 组件，按帧算动画
- Motion Canvas motion: TS 写动画，擅长旁白同步
- ManimGX: Python 写场景，Rust/GPU 渲染
	
🧠 让它越做越好
- huashu-art-motion: 35 种视觉风格，先把设计要求写成 AI 能执行的约束
- ManimAgent: 把上次的修复经验存起来，下次直接复用
	
这条路线现在还很糙，对基模能力要求很高，跑一次经常要改好几轮，但方向是对的——只要动画是代码，就能被迭代👍
