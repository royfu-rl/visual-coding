# 7个用AI做动画的Skills

- 命中关键词：HyperFrames、Motion Canvas

想用 AI 做动画，不知道该装什么？
	
这期给你一次讲清，这7个AI动画必用skills👇
	
1️⃣ HyperFrames｜HeyGen 做的
只要你写网页代码，它就能帮你变成影片。会写前端的人，这是最省力的入口 🧑‍💻
	
2️⃣ GSAP｜网页动效库
网页上那种会浮动、会弹跳、有质感的动效，就是靠它教 AI 写出来的 ✨
	
3️⃣ Pixel2Motion｜一张图就够
给它一张 Logo 图，自动变成一段会动的开场动画。片头党狂喜 🎞️
	
4️⃣ Remotion｜用写程序的方式做视频
最适合数字、图表这类动画。数据改了，视频跟着改 📊
	
5️⃣ Video-Shotcraft｜100+ 现成电影镜头
把网站画面丢进去，帮你剪成一支有电影感的广告片 🎥
	
6️⃣ story-to-handdrawn-video｜打中文就行
打个中文故事，它会变成手绘日记动画。爱讲故事的一定要试试 ✍️
	
7️⃣ motion-design-skill｜它不太一样
它教的是手感——画面上那种点阵会呼吸、有节奏的效果，就是它管的 🫧
	
一句话选型 👇
有代码 → 01｜有 Logo → 03｜有网站 → 05｜有数据 → 04
什么都没有，只有一个想讲的故事 → 06
	
前五个决定你能不能做出来，后两个决定做出来好不好看 🙌
