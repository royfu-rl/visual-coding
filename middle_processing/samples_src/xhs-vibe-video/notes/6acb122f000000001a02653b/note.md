6. Short Drama Pipeline · Codex Skill
把创意拆成完整生产包：受众 → 剧本 → 角色 → 场景道具 → 分镜 → 提示词 → 生成记录 → QC → 发布包。

用于专业短剧生产总控，把大纲、角色、美术、剧本、导演、技术分镜、声音、粗剪和 QC 串成可追踪、可返工的生产链。
8. Video Agent Skills  ⭐
把小说、剧本或剧情片段转成短剧资产，包括角色/场景/道具拆解、分镜表和视频组提示词。
9. Puhua Short Drama Skill  ⭐
用于微短剧编剧，从选题、分集结构、剧本、自检、合规到出海版本输出，也可接生图、生视频流程。
