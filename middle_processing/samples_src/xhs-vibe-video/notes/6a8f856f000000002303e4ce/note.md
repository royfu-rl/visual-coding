# MiniMax H3被 fal 重新训练，效果反超原版

- 作者：SI小小将　类型：normal　赞 271 / 藏 287 / 评 44
- 链接：https://www.xiaohongshu.com/explore/6a8f856f000000002303e4ce?xsec_token=AB5yE1q7D9BLH98diPW2g3l6lg_KLnTribSAAxkv30w1U=&xsec_source=pc_search
- 命中关键词：Hypit 视频

MiniMax H3 又被二次训练了一版，而且成绩还不错。
fal 基于开源的 MiniMax H3 做了后训练，推出了 MiniMax H3 Max。
	
📊 Artificial Analysis 最新成绩
• 图生视频 + 音频：第 1 名
• 文生视频 + 音频：第 3 名
• 两项都超过了原版 MiniMax H3
• 图生视频这一项，还小幅领先 SD 2.0 720p
	
这次 fal 主要做了几件事：
🔹 加入新的后训练数据，重点提升 Prompt 遵循和画面美感
🔹 花了不少算力做 verifiable RL
🔹 针对 fal 自家的推理引擎做了联合优化
	
⚡️ 速度也提升得比较明显
fal 表示，H3 Max 生成一个 5 秒 720p 视频不到 3 秒，吞吐量大约是官方 H3 接口的 35 倍。目前支持：
• 5～15 秒视频
• 原生音频
• 最高 768p
	
💰 价格反而更低
• H3 Max：0.04 美元/秒
• 原版 H3：0.06 美元/秒
	
也就是一分钟 768p 视频大约 2.4 美元。
另外，fal 已经表示后续计划开放 H3 Max 权重。
