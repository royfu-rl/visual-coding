最近很多人用 Opus 5.5 写代码做动画视频，画面、字幕、导出全靠代码，不用剪辑软件。
真正上手会发现，让 Agent 先装好对应的 Skill，写出来的代码会规范很多。我把常用的几个按做视频的步骤整理了一下：
1. 定风格：frontend-design，Anthropic 官方 Skill 库里的
2. 写动画代码：remotion-best-practices（Remotion 官方），或者用 HyperFrames 的 hyperframes，直接写 HTML
3. 配素材和声音：media-use，HyperFrames 仓库里的
4. 加字幕：Remotion 的 remotion-captions
5. 导出 MP4：Remotion 的 remotion-render
	
新手的话，直接让 Agent 帮你装 Remotion 官方那套就够了，先做 10 秒，跑通再做长。
