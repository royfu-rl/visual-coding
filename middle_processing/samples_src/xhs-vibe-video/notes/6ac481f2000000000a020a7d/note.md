# 4DCodeBench｜让Agent写代码复刻物理世界

- 作者：糯米兔的炼丹炉　类型：normal　赞 162 / 藏 137 / 评 14

- 命中关键词：AI 写代码做动画、代码生成视频

暑研的工作 release 啦！
	
牛顿定律仅仅几行，而寥寥数秒的视频却拥有天文数字的状态组合。我们应该如何构建一种高效简洁的中间表征?
	
利用代码生成的世界，天然是可编辑、可组合的，当 world modeling 的视角从 latent space 延伸到 explicit world space，我们能否借由VLM，把物理世界，转化为 blender world space里的一段代码？更进一步，what if 从物理定律支配的物体动态，到智能体的行动，甚至某些 social behavior，都能在适当的抽象层次上被表达、组合和推演？VLM是否能在未来表征这个世界的“底层代码”？
	
4DCodeBench 是对这件事的一次早期探索：给 Coding Agent 一段物理动态视频，让它通过代码重建其中的几何、外观和动态。
	
4DCodeBench固然还有很多不完美，例如我们无法给出足够好的自动化指标，判断某一现象是否ground in physics；我们仅停留在重建上，而没有涉足机器人real2sim、对于未来的preidction等话题。 但我们希望这个可以作为驱动VLM能力提升，让VLM能够以coding的形式，去成为更好的world simulator。
