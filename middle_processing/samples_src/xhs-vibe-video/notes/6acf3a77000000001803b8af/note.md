作者是mexicat，甚至将此项目开源了～
这支音乐视频完全通过 Claude Opus 5.5 + Claude Code 协作完成。
从创意构思、视觉设计、歌词同步、音频分析，到场景动画、渲染引擎开发和最终输出，全部通过与 Claude 的对话完成。
更厉害的是，它并不是传统的 AI 文生视频，而是通过代码实时生成画面。
整个项目基于 TypeScript + three.js，结合音频节拍分析、逐词歌词对齐和程序化动画，让画面、文字与音乐精准同步。
项目使用的核心技术：
1. AI 开发
Claude Opus 5.5：创意构思、视觉设计、代码生成
Claude Code：项目开发、调试与迭代
2. 音频分析
Python + uv：音频分析工具链
Demucs：人声与伴奏分离
Whisper：语音识别与歌词校验
CTC Forced Alignment：歌词逐词、逐音节时间对齐
Beat / Downbeat Detection：节拍与强拍检测
Onset Detection：鼓点、人声起音检测
Loudness Analysis：音频响度分析
3. 视觉生成
TypeScript：核心开发语言
three.js：3D 图形与程序化动画
WebGL / GPU：实时图形渲染
Procedural Animation：程序化动画
Kinetic Typography：动态文字排版
Bloom / Halation / Grain：辉光、光晕与胶片颗粒
4. 渲染与导出
Bun + Vite：开发与构建环境
Headless Chrome：无界面浏览器逐帧渲染
WebSocket：原始视频帧传输
FFmpeg：视频编码与导出
Deterministic Rendering：确定性渲染，保证相同时间参数对应相同画面
