Chrome 149+: shape() in shape-outside

This paragraph demonstrates how the new CSS shape() function can be combined with the shape-outside property to wrap text along a non-rectangular boundary.

The squiggly line is created by chaining a series of curve to commands. Each curve takes a destination coordinate and a control point using the with keyword to create smooth quadratic Bézier curves. By alternating the X coordinates of the destination points and their control points, we generate a wave pattern that runs down the right edge of the floated element.

The same exact shape() function is applied to the clip-path property. This trims the background gradient of the floated container to perfectly match the invisible barrier pushing against the text.
