<h1 class=no-toc id=what-is-ngrx>What is NgRx?<a title="Link to this heading" class=header-link aria-hidden=true href=#what-is-ngrx><i class=material-icons>link</i></a></h1>
<p>NgRx is a framework for building reactive applications in Angular. NgRx provides libraries for:</p>
<ul>
<li>Managing global and local state.</li>
<li>Isolation of side effects to promote a cleaner component architecture.</li>
<li>Entity collection management.</li>
<li>Integration with the Angular Router.</li>
<li>Developer tooling that enhances developer experience when building many different types of applications.</li>
</ul>
<h2 id=packages>Packages<a title="Link to this heading" class=header-link aria-hidden=true href=#packages><i class=material-icons>link</i></a></h2>
<p>NgRx packages are divided into a few main categories</p>
<h3 id=state>State<a title="Link to this heading" class=header-link aria-hidden=true href=#state><i class=material-icons>link</i></a></h3>
<ul>
<li><a href=https://ngrx.io/guide/store>Store</a> - RxJS powered global state management for Angular apps, inspired by Redux.</li>
<li><a href=https://ngrx.io/guide/effects>Effects</a> - Side effect model for @ngrx/store.</li>
<li><a href=https://ngrx.io/guide/router-store>Router Store</a> - Bindings to connect the Angular Router to @ngrx/store.</li>
<li><a href=https://ngrx.io/guide/entity>Entity</a> - Entity State adapter for managing record collections.</li>
<li><a href=https://ngrx.io/guide/signals>Signals</a> - Reactive store and set of utilities for Angular Signals.</li>
<li><a href=https://ngrx.io/guide/component-store>ComponentStore</a> - Standalone library for managing local/component state.</li>
<li><a href=https://ngrx.io/guide/operators>Operators</a> - Shared RxJS operators for NgRx libraries.</li>
</ul>
<h3 id=data>Data<a title="Link to this heading" class=header-link aria-hidden=true href=#data><i class=material-icons>link</i></a></h3>
<ul>
<li><a href=https://ngrx.io/guide/data>Data</a> - Extension for simplified entity data management.</li>
</ul>
<h3 id=view>View<a title="Link to this heading" class=header-link aria-hidden=true href=#view><i class=material-icons>link</i></a></h3>
<ul>
<li><a href=https://ngrx.io/guide/component>Component</a> - Extension for building reactive Angular templates.</li>
</ul>
<h3 id=developer-tools>Developer Tools<a title="Link to this heading" class=header-link aria-hidden=true href=#developer-tools><i class=material-icons>link</i></a></h3>
<ul>
<li><a href=https://ngrx.io/guide/store-devtools>Store Devtools</a> - Instrumentation for @ngrx/store that enables visual tracking of state and time-travel debugging.</li>
<li><a href=https://ngrx.io/guide/schematics>Schematics</a> - Scaffolding library for Angular applications using NgRx libraries.</li>
<li><a href=https://ngrx.io/guide/eslint-plugin>ESLint Plugin</a> - ESLint rules to warn against bad practices. It also contains a few automatic fixes to enforce a consistent style, and to promote best practice.</li>
</ul>
